# OmniDocs-template

Maximalist **Starlight documentation site** template: Astro + Starlight,
**bun**, biome, `astro check`, GitHub Pages deploy on every merge to main —
nix flake + dual devcontainers + VS Code. Built to match the estate's
existing doc sites (starlight-sites). Part of the
[WyattAu Omni family](https://github.com/WyattAu?tab=repositories&q=omni-).

## Start here (after "Use this template")

1. Rename: site title/description/socials in `astro.config.mjs`; sidebar to
   your sections.
2. Enable **Settings → Pages → Source: GitHub Actions** once.
3. Pick a door — nix / devcontainer(image|nix) / `./scripts/bootstrap.sh`.
4. `bun install && make ci` — must be green before your first push.

## Make targets

| Target | Gate |
|---|---|
| `make build` | `astro build` (Starlight content inspection + static output) |
| `make typecheck` | `astro check` |
| `make lint` / `fmt` | biome |
| `make contract` / `make ci` | contract / contract + fmt-check + lint + typecheck + build |

CI adds the estate node gate (`node-ci.yml`, bun, test:false) and both
devcontainer builds. Deploy is zero-touch after Pages is enabled (ADR-0002).

## Content conventions

- Guides under `src/content/docs/guides/`, reference under `reference/`
  (autogenerated sidebar).
- Sidebar wiring in `astro.config.mjs`; estate theming via
  `src/styles/custom.css` (Starlight `customCss` hook).
